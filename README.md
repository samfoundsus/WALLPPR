# WALLPPR

A premium procedural wallpaper generator built for creating unique, minimal, and highly customizable wallpapers.

Generate wallpapers from procedural styles, control their composition, colors, dimensions, and export them in high quality.

## Features

- 10 procedural wallpaper styles
- Seed-based deterministic generation
- Multiple curated color palettes
- Light & dark wallpaper modes
- Custom dimensions
- Geometry & composition controls
- Random & Regenerate generation
- PNG, JPG & 4× export
- Responsive premium interface
- Fully client-side generation

## Styles

Hills · Waves · Arcs · Blobs · Rings  
Mesh · Contour · Orbit · Cells · Stripes

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML Canvas

## Run Locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
